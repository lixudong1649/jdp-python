# 关于

**Python 读码实战课**：面向有 JS / Java 经验开发者的中文 Python 课程，11 个阶段、36 课，终点是逐行读懂 `minimal_agent.py`。工程结构见 [项目架构与技术栈](项目架构与技术栈.md)。
