# Python 学习路线

## 目标

**最低目标：了解 Python、能看懂代码。** 能读懂 [examples/agent/minimal_agent.py](../examples/agent/minimal_agent.py) 这类百行脚本：说出每行在做什么、数据如何流动、出错时能定位到哪一行。

不在本路线范围：Web 框架、数据分析、并发编程、打包发布等方向性内容。

## 使用方式

- 按阶段顺序学习；每阶段学完对应课程（或读一份官方文档）并完成一个小练习即可前进。
- 主教材为本项目课程（[课程大纲](课程大纲.md)，正文在 `docs/课程/`）：每阶段下的“课程”列出对应课，含可运行示例与自动判题练习。
- 官方 [Python 教程（中文）](https://docs.python.org/zh-cn/3/tutorial/index.html) 作为延伸阅读，各阶段“延伸阅读”链接均指向其中对应章节。
- 练习统一在本项目内运行：`uv run python`（交互式）或 `uv run 文件.py`。练习文件放 `practice/`（可自建，按阶段命名，如 `practice/03_函数.py`）。

## 1. 环境与工具

- **目标**：在本项目中运行 Python 代码，理解“项目环境”与“系统 Python”的区别。
- **核心概念**：解释器、虚拟环境 `.venv`、`pyproject.toml`、`uv.lock`、`uv run` / `uv add`、交互式解释器（REPL）。
- **课程**：[1.1 运行 Python 代码](课程/01-环境与工具/01-运行Python代码.md) · [1.2 uv 项目与依赖](课程/01-环境与工具/02-uv项目与依赖.md)（[阶段导读](课程/01-环境与工具/index.md)）
- **延伸阅读**：[Python 概览与环境](Python概览与环境.md)（本项目）；[使用 Python 解释器](https://docs.python.org/zh-cn/3/tutorial/interpreter.html)；[uv 项目工作流](https://docs.astral.sh/uv/guides/projects/)。
- **练习**：执行 `uv run python --version` 与 `python3 --version`，解释两者为何可能不同；在 `uv run python` 中输入 `import this`。

- **练习**：写 `def get_weather(city): ...`，分别用 `get_weather("北京")`、`get_weather(city="北京")`、`get_weather(**{"city": "北京"})` 调用，确认三者结果相同。

## 10. 读代码技巧

- **目标**：形成读陌生代码的固定步骤。
- **方法**：
  1. 先看入口与整体：文件头文档字符串、`import`、顶层常量、主流程（循环或 `main`）。
  2. 跟踪核心数据：找出关键变量（如 `messages`），记录它在哪些行被创建、修改、读取。
  3. 遇到不认识的名字：判断来自内置、标准库还是第三方包，再查对应文档；在 `uv run python` 中用 `help(对象)`、`type(值)`、`dir(对象)` 实验。
  4. 不确定就运行：加 `print()` 观察中间值，或缩小成最小片段在解释器里试。
- **课程**：[10.1 迭代器与生成器](课程/10-读代码技巧/01-迭代器与生成器.md) · [10.2 装饰器](课程/10-读代码技巧/02-装饰器.md) · [10.3 读陌生代码的方法](课程/10-读代码技巧/03-读陌生代码的方法.md) · [10.4 读第三方 SDK 代码](课程/10-读代码技巧/04-读第三方SDK代码.md)（[阶段导读](课程/10-读代码技巧/index.md)）
- **延伸阅读**：[术语对照表](https://docs.python.org/zh-cn/3/glossary.html)；[PEP 8 代码风格](https://peps.python.org/pep-0008/)（了解命名约定，如全大写表示常量）。
- **练习**：不看注释，画出 `minimal_agent.py` 中 `messages` 在两轮循环后的结构。
