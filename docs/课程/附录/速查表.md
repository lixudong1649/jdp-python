## 语法骨架

```python
"""模块文档字符串。"""
import os                                  # 标准库
from dataclasses import dataclass          # 从模块导入名字

MAX_TURNS = 5                              # 常量（约定）


@dataclass
class Tool:
    name: str

    def run(self, **kwargs) -> str:        # 方法：self + 任意关键字参数
        return f"{self.name}({kwargs})"


def main() -> None:
    for turn in range(1, MAX_TURNS + 1):   # 1..5
        if turn == 3:
            break
    else:
        print("没有 break 时执行")


if __name__ == "__main__":                 # 仅直接运行时执行
    main()
```

## 值与运算

| 写法 | 结果 / 含义 |
|---|---|
| `7 / 2`、`7 // 2`、`7 % 2`、`2 ** 10` | `3.5`、`3`、`1`、`1024` |
| `a or b` | `a` 为真返回 `a`，否则 `b`（常用于默认值） |
| `a and b` | `a` 为假返回 `a`，否则 `b` |
| `x if cond else y` | 条件表达式 |
| `x is None` | 判断 None（不要用 `==`） |
| `0 < x <= 10` | 链式比较 |
| 假值 | `None`、`False`、`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()` |

| 写法 | 含义 |
|---|---|
| `f"{x}"`、`f"{x:.2f}"`、`f"{x:>8}"`、`f"{x=}"` | 插值、两位小数、右对齐宽 8、调试输出 |

## 容器

| 操作 | list | dict | set |
|---|---|---|---|
| 字面量 | `[1, 2]` | `{"k": 1}` | `{1, 2}`（空集合 `set()`） |
| 添加 | `xs.append(x)` / `extend` | `d[k] = v` / `update` | `s.add(x)` |
| 删除 | `xs.pop()` / `remove(x)` | `d.pop(k)` / `del d[k]` | `s.discard(x)` |
| 读取 | `xs[0]`、`xs[-1]` | `d[k]`（缺键抛错）、`d.get(k, 默认)` | — |
| 包含 | `x in xs` | `k in d`（判断键） | `x in s` |
| 遍历 | `for i, x in enumerate(xs)` | `for k, v in d.items()` | `for x in s` |
| 合并 | `[*a, *b]` / `a + b` | `a \| b` / `{**a, **b}` | `a \| b` |
| 推导式 | `[f(x) for x in xs if p(x)]` | `{k: v for k, v in d.items()}` | `{f(x) for x in xs}` |

切片：`xs[start:stop:step]`，含头不含尾，越界不报错。解包：`a, *rest = xs`、`for k, (x, y) in ...`。

## 函数

| 写法 | 含义 |
|---|---|
| `def f(a, b=1)` | 位置参数 + 默认值（默认值定义时求值一次，勿用可变对象） |
| `def f(*args, **kwargs)` | 收集多余位置参数（tuple）/ 关键字参数（dict） |
| `def f(a, /, b, *, c)` | `a` 仅限位置，`c` 仅限关键字 |
| `f(*xs)`、`f(**d)` | 调用时展开序列 / 字典 |
| `lambda x: x * 2` | 单表达式匿名函数 |
| `sorted(xs, key=lambda x: x["n"])` | 按键排序 |
| `@deco` | 等价于 `f = deco(f)` |
| `nonlocal x` / `global x` | 在函数内重新绑定外层 / 全局名字 |

## 异常

```python
try:
    value = risky()
except (KeyError, ValueError) as e:        # 具体异常，写在前
    log.warning("失败：%s", e)
    raise CustomError("说明") from e       # 保留原因
except Exception:
    raise                                  # 原样重抛
else:
    print("无异常时执行")
finally:
    print("总会执行")
```

| 异常 | 常见原因 |
|---|---|
| `NameError` | 名字未定义 / 拼写错误 / 忘记导入 |
| `TypeError` | 类型不对、参数个数或名字不对 |
| `ValueError` | 值不合法（`int("abc")`） |
| `KeyError` / `IndexError` | dict 缺键 / 下标越界 |
| `AttributeError` | 对象没有该属性（常见：意外的 `None`） |
| `ModuleNotFoundError` | 未在项目环境运行 / 包名与导入名不同 |

Traceback：先看最后一行，再从下往上找自己的代码。

## 类

| 写法 | 含义 |
|---|---|
| `class B(A):` / `super().__init__()` | 继承 / 调用父类 |

| `@dataclass(frozen=True)`、`field(default_factory=list)` | 数据类、不可变、可变默认值 |

## 类型注解

| 写法 | 含义 |
|---|---|
| `def f(x: int) -> str` | 参数与返回值注解（运行时不检查） |
| `list[str]`、`dict[str, int]`、`tuple[int, ...]` | 容器泛型 |
| `str \| None` = `Optional[str]` | 可为 None |
| `Literal["a", "b"]` | 取值限定 |
| `TypedDict` | 描述 dict 结构（SDK 的 `*Param`） |
| `Callable[[int], str]`、`Iterable[T]` | 可调用对象、可迭代对象 |
| `def f[T](x: T) -> T`、`type Alias = ...` | 3.12 起泛型语法 |
