# 阶段 10 · 读代码技巧

**达成标志**：拿到一份陌生代码或一个第三方 SDK，能按固定步骤读懂主流程，并能顺着源码找到任意名字的定义。

| 课程 | 你将学会 |
|---|---|
| [10.1 迭代器与生成器](01-迭代器与生成器.md) | 迭代协议、`yield`、生成器表达式、惰性求值（读码层面） |
| [10.2 装饰器](02-装饰器.md) | `@decorator` 的本质、`functools.wraps`、带参数的装饰器、常见内置装饰器 |
| [10.3 读陌生代码的方法](03-读陌生代码的方法.md) | 入口 → 数据 → 名字来源 → 实验验证；`help`/`dir`/`type`/`inspect`/`breakpoint` |
| [10.4 读第三方 SDK 代码](04-读第三方SDK代码.md) | 从 `client.messages.create` 一路追到源码；读懂 SDK 的常见模式 |

**与终点的关系**：读完本阶段，你已具备逐行读懂 `minimal_agent.py` 以及它所调用 SDK 的全部工具。
