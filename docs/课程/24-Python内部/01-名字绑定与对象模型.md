# 24.1 名字绑定与对象模型

> 前置：2.1 语法骨架 · 约 25 分钟 · 官方对应：[命名与绑定](https://docs.python.org/zh-cn/3/reference/executionmodel.html#naming-and-binding)

## 目标

- 名字是标签，对象是独立实体
- 赋值不复制对象，只绑定名字

## 核心概念

```python run
a = [1, 2]
b = a
b.append(3)
print(a, b is a)
```

## 易错点

- 默认参数可变对象陷阱。
- `is` 与 `==` 不同。

## 读代码

messages 列表在多轮中原地修改；多个名字可指向同一 list。

## 练习

```python exercise id=s24-l01-bind
# --- starter ---
x = [1]
y = x
# --- solution ---
x = [1]
y = x
x.append(2)
# --- check ---
assert y == [1, 2]
```

## 小结

- 赋值绑定名字
- 可变对象共享
