# 24.1 名字绑定与对象模型

> 前置：2.1 语法骨架、3.4 闭包 · 约 40 分钟 · 官方对应：[命名与绑定](https://docs.python.org/zh-cn/3/reference/executionmodel.html#naming-and-binding) · 核对日期 2026-10-18

## 目标

- 建立 **名字是标签、对象是堆上实体** 的心智模型；赋值 `=` 只做绑定，不复制对象。
- 区分 **可变** 与 **不可变** 对象（`list` vs `tuple`/`str`），理解共享引用带来的副作用。
- 掌握 **`is` 与 `==`**：`is` 比较身份（同一对象），`==` 比较值。
- 读懂 Agent 会话里 `messages` 列表被多轮原地追加时的行为。
- 能解释为何 `copy.copy` 不能解决嵌套 list 的共享问题。

## 核心概念

### 赋值即绑定

```python run
a = [1, 2]
b = a
b.append(3)
print(a, b is a)
```

`a` 与 `b` 绑定到同一个 list 对象；`append` 原地修改，两边都看见。

### 不可变对象“像复制”

```python run
x = "hello"
y = x
x = x + "!"
print(y, x)
print(y is x)
```

`x = x + "!"` 创建新字符串并重新绑定 `x`；`y` 仍指向旧串。

### 默认参数陷阱

```python run
def append_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

print(append_item(1))
print(append_item(2))
```

每次调用新建列表，避免 `def f(bucket=[])` 共享同一默认 list。

### 浅拷贝与深拷贝

```python run
import copy

outer = [[1], [2]]
shallow = copy.copy(outer)
deep = copy.deepcopy(outer)
outer[0].append(99)
print(shallow[0], deep[0])
```

浅拷贝共享嵌套对象；深拷贝递归复制。

### `is` 与 `==`

```python run
a = [1, 2, 3]
b = [1, 2, 3]
print(a == b, a is b)
c = a
print(a is c)
```

## 易错点

- **`is` 判断相等**：应使用 `==`；`is` 只用于与 `None`、单例比较等小范围场景。
- **函数默认可变参数**：`def f(xs=[])` 默认值只创建一次，跨调用泄漏状态。
- **元组含可变元素**：`t = ([1],)` 里 list 仍可改，`t[0].append(2)` 合法。
- **del 只删名字**：`del a` 不销毁对象，只解除绑定；对象由引用计数回收。

```python run raises=TypeError
t = (1, 2, 3)
t[0] = 0
```

| 概念 | Python | JavaScript | Java |

| 变量语义 | 名字绑定到对象 | `let` 绑定、对象引用 | 引用类型 |
| 不可变数字/串 | `int`/`str` 不可变 | 原始类型不可变 | `String` 不可变 |
| 相等 | `==` 值，`is` 身份 | `===` | `equals` / `==` |
| 默认参数 | 求值一次 | 同 | 无（重载） |

## 读代码

`examples/agent/minimal_agent.py` 中对话历史是 **可变 list**，多轮循环里原地 `append`：

```python
messages = [{"role": "user", "content": "上海今天天气怎么样？"}]

for turn in range(1, MAX_TURNS + 1):
    resp = client.messages.create(
        model=model,
        max_tokens=1024,
        tools=tools,
        messages=messages,
    )
    messages.append({"role": "assistant", "content": resp.content})
```

读法：

1. `messages` 名字始终绑定同一个 list 对象；每轮 `append` 增长长度，不重新赋值 `messages = [...]`。
2. SDK 读取的是当前 list 快照引用；理解“传可变容器进 API”时要清楚谁在改内容。
3. 若写 `messages = messages + [new]` 会创建新 list 并重新绑定，旧引用不会更新——Agent 里应避免无意重绑。
4. `resp.content` 可能是复杂结构，仍作为单个元素追加；别假设全是字符串。
5. 调试时 `print(len(messages), id(messages))` 可确认是否同一对象。

阶段 23 `REGISTRY` 是模块级 **可变 dict**，`@tool` 注册时原地写入键，与 list append 同属“共享可变全局”模式，读代码时要警惕测试顺序依赖。

## 练习

### 练习 1：共享 list

```python exercise id=s24-l01-bind
# --- starter ---
x = [1]
y = x
# --- solution ---
x = [1]
y = x
x.append(2)
# --- check ---
assert y == [1, 2]
```

### 练习 2：安全默认桶

```python exercise id=s24-l01-bucket
# --- starter ---
def add(v, bucket=[]):
    bucket.append(v)
    return bucket
# --- solution ---
def add(v, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(v)
    return bucket
# --- check ---
assert add(1) == [1]
assert add(2) == [2]
```

### 调试习惯

遇到“列表怎么突然变了”，在 REPL 打印 `id(lst)` 与 `sys.getrefcount`（仅作线索）。Agent 代码里优先查是否多处持有 `messages` 引用，而不是怀疑 CPython 复制语义。

元组解包 `a, b = b, a` 会同时创建临时元组并重新绑定，不涉及交换对象内容。列表切片 `lst[:]` 是浅拷贝新 list，元素仍是同一引用。

函数形参重新赋值（`name = name + suffix`）只改局部绑定，不影响调用方传入的不可变对象。

## 小结

- Python 赋值是绑定；可变对象通过共享引用产生副作用。
- 默认参数不要用可变字面量；需要时用 `None` 哨兵。
- 读 Agent 代码先看 `messages`、`REGISTRY` 等是否原地修改。
- `is` 与 `==` 分工明确，避免混用。
- 全局 `global`、嵌套 `nonlocal` 改变绑定规则，闭包课已涉及。
- 类属性与实例属性绑定在不同命名空间，读 `self.x` 时分清。
- 导入的名字也是绑定，重绑定模块内变量不影响已导入的别名对象。
- 小对象频繁创建由引用计数立即回收，一般无需手动 `del`。
- 读 C 扩展对象时 `is` 行为不变，仍比较身份。
- 不可变对象可作 dict 键，可变 list 不能作键。
- 枚举成员是单例，比较可用 `is`。
- 描述符与 `property` 改变属性访问时的绑定行为，进阶再学。
- `+=` 对可变对象可能原地修改，对不可变对象重新绑定。
- 读第三方库时查是否返回内部可变缓存。
- 核对日期 2026-10-18：对象模型在 3.12 与 3.11 对学习者一致。
- 元类改变类创建过程，日常业务代码很少手写。
- `frozen=True` 的 dataclass 实例字段不可赋，接近不可变记录。
- 列表乘法会浅复制元素引用，`[[0]]*3` 三行共享同一 list。
- 绑定在编译期确定作用域，LEGB 规则见官方 execution model。
- 通过参数传递子列表时，调用方仍持有原列表引用。

写 Agent 历史时，若需要“快照”某一轮消息，用 `copy.deepcopy(messages)` 而不是赋值别名。

核对日期 2026-10-18：3.12 对象模型与 3.10 对学习者无重大差异，重点仍是可变与不可变。

- `tuple` 打包解包在字节码层由 `BUILD_TUPLE` 等完成，与绑定课衔接见 24.2。
- 读 `REGISTRY` 时记住 dict 的键是名字字符串，值是函数对象引用。
- 用 `id()` 调试时小整数可能因缓存出现相同 id，勿过度解读。
