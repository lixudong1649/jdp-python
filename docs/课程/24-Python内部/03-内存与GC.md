# 24.3 内存与 GC

> 前置：24.1 名字绑定 · 约 25 分钟 · 官方对应：[gc 模块](https://docs.python.org/zh-cn/3/library/gc.html)

## 目标

- 引用计数为主，循环引用靠 gc
- 弱引用了解即可

## 核心概念

```python run
import sys
a = []
print(sys.getrefcount(a) >= 1)
```

## 易错点

- 循环引用需要 gc 收集。
- 大对象注意 __slots__（进阶）。
