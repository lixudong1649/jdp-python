# 24.4 导入系统

> 前置：5.1 模块与 import · 约 25 分钟 · 官方对应：[importlib](https://docs.python.org/zh-cn/3/library/importlib.html)

## 目标

- 理解 sys.modules 缓存
- 包相对导入与 __package__

## 核心概念

```python run
import sys
print("sys" in sys.modules)
```

## 易错点

- 循环 import 导致部分初始化。
- 动态 import 难静态分析。

## 对照

## 读代码

读项目先看 import 块；第三方包在 site-packages。

## 练习

```python exercise id=s24-l04-imp
# --- starter ---
name = 'sys'
# --- solution ---
import json
name = json.__name__
# --- check ---
assert name == 'json'
```

## 小结

- 首次 import 执行模块顶层
- sys.modules 缓存
