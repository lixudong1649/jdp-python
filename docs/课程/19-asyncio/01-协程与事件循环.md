# 19.1 协程与事件循环

> 前置：18. 并发 · 约 25 分钟 · 官方对应：[asyncio 入门](https://docs.python.org/zh-cn/3/library/asyncio.html)

## 目标

- 定义 async def 与 await
- 用 asyncio.run 驱动

## 核心概念

```python run
import asyncio
import inspect

async def main():
    return 42

print(inspect.iscoroutinefunction(main))
```

## 易错点

- 在 async 函数里调用阻塞 IO 会卡住 loop。
- 忘记 await 得到 coroutine 对象。
