# 14.2 re 正则

> 前置：8. 常用标准库 · 约 25 分钟 · 官方对应：[re 模块](https://docs.python.org/zh-cn/3/library/re.html)

## 目标

- 会用 search/findall
- 知道原始字符串 r"..."

## 核心概念

```python run
import re
m = re.search(r"\d+", "temp=22C")
print(m.group(0) if m else None)
```

## 易错点

- 贪婪匹配导致过多捕获。
- 复杂正则难维护，优先 str 方法。

## 读代码

日志解析、路径提取会见到 re；先读模式字符串再读 group。

## 练习

```python exercise id=s14-l02-re
# --- starter ---
import re

m = re.search('z', 'cat')
# --- solution ---
import re

m = re.search('a', 'cat')
# --- check ---
assert m and m.group(0) == 'a'
```

## 小结

- 原始字符串减少转义
- search 找首个匹配
