# 14.2 re 正则

> 前置：2.3 字符串 · 约 35 分钟 · 官方对应：[re 模块](https://docs.python.org/zh-cn/3/library/re.html)

## 目标

- 用 `re.search` / `re.findall` 从日志、配置行里提取子串；会用 **原始字符串** `r"..."` 写模式。
- 理解 `Match.group()`、预编译 `re.compile`，以及 `\b` 词边界在日志级别匹配里的作用。
- 知道贪婪与非贪婪量词，并养成“能用 `str` 方法就不用正则”的习惯。
- 能读懂阶段项目 `logstats` 里的 `LEVEL_RE` 与 `parse_lines` 循环。

## 核心概念

### 第一个匹配：search

`re.search(pattern, string)` 在**整个字符串**里找**第一个**匹配；找不到返回 `None`。

```python run
import re

line = "room temp=22C humidity=55"
for label, pat in [("temp", r"temp=(\d+)"), ("humidity", r"humidity=(\d+)")]:
    m = re.search(pat, line)
    if m:
        print(label, "value", m.group(1), "span", m.span(1))
first_digit = re.search(r"\d+", line)
print("first digit anywhere", first_digit.group(0), "at index", first_digit.start())
chunks = re.findall(r"(temp|humidity)=\d+", line)
print("all key=value chunks", chunks)
print("chunk count", len(chunks))
```

`search` 在整行里找**第一个**匹配；带捕获组时 `group(1)` 只取括号里的数字，比 `group(0)` 更贴近「提取字段」的用法。`findall` 列出本行里所有 `temp=` / `humidity=` 片段，与只取首个数字的 `search` 形成对比。
`group(0)` 是整段匹配；若模式里有括号捕获，`group(1)` 是第一组。

### 原始字符串

正则里反斜杠很多；用 `r"\d+"` 比 `"\\d+"` 更清晰，也少踩转义坑。

```python run
import re

text = "a\nb"
raw_pat = "\\n"
r_pat = r"\n"
print("literal backslash-n matches newline?", re.search(raw_pat, text) is not None)
print("raw string \\n matches newline?", re.search(r_pat, text) is not None)
print("patterns equal?", raw_pat == r_pat)
print("repr raw", repr(raw_pat), "repr r", repr(r_pat))
```

普通字符串里要写 `\\n` 才表示正则的「换行」；`r"\n"` 少一层转义，模式与 `\\n` 等价。输出里 `repr` 对比能看清 Python 字符串层与正则层的差别。

### findall 与 compile

重复使用的模式应 `compile` 一次；`findall` 返回所有非重叠匹配（无捕获组时返回字符串列表）。

```python run
import re

log = "GET /api OK ERROR retry ERROR"
pat = re.compile(r"[A-Z]{2,}")
hits = pat.findall(log)
print("findall", hits)
print("count ERROR tokens", hits.count("ERROR"))
compiled_again = re.compile(r"[A-Z]{2,}")
print("same pattern object?", pat.pattern == compiled_again.pattern)
print("non-overlap: GET then OK not GO from GET")
```

`findall` 返回所有非重叠的大写词；`compile` 把模式缓存成对象，大文件里比每次传字符串更高效。注意 `GET` 与 `OK` 是分开匹配的，不会从 `GET` 里再抠出 `GE`。

`\b` 表示“单词字符与非单词字符的分界”。阶段项目用 `\b(INFO|WARNING|ERROR|DEBUG)\b`，避免把 `MYINFO` 里的子串误当成级别。

```python run
import re

LEVEL_RE = re.compile(r"\b(INFO|WARNING|ERROR|DEBUG)\b")
line = "2026-01-01 INFO started MYINFO ignored"
m = LEVEL_RE.search(line)
print(m.group(1) if m else None)
```

### 多行文本

`parse_lines` 对整段 `text` 按行切分再 `search`，等价于对每行找首个级别；不需要 `re.MULTILINE` 也能工作，因为每次 `search` 的字符串只是一行。

```python run
import re
from collections import Counter

LEVEL_RE = re.compile(r"\b(INFO|WARNING|ERROR|DEBUG)\b")
text = "x INFO one\ny ERROR two\nz INFO three\n"
counts: Counter[str] = Counter()
for line in text.splitlines():
    m = LEVEL_RE.search(line)
    if m:
        counts[m.group(1)] += 1
print(dict(counts))
```

### 捕获组

括号 `(...)` 会多出一个 **捕获组**；`group(0)` 仍是整段匹配，`group(1)` 是第一组。日期前缀 + 级别可写成一条模式，便于以后扩展。

```python run
import re

lines = [
    "2026-01-01 INFO boot",
    "2026-02-02 ERROR disk",
    "no-date DEBUG trace",
]
pat = re.compile(r"(\d{4}-\d{2}-\d{2})\s+(\w+)")
for line in lines:
    m = pat.search(line)
    if m:
        print("date", m.group(1), "token", m.group(2), "full", m.group(0))
    else:
        print("skip", line)
```

第一组捕获日期、第二组捕获紧跟的「词」（这里是日志级别）；无日期前缀的行不会匹配，循环里要处理 `None`。这与 `logstats` 里「先整行 search 再取 group(1)」同一套路，只是模式里多留了日期字段供扩展。

## 易错点

- **贪婪 `.*`**：会吞掉过多内容；需要时用 `.*?` 或非贪婪模式，或改用更具体的字符类。
- **不检查 `search` 返回值**：`None.group()` 会 `AttributeError`；先 `if m:` 或用 `m.group(1) if m else default`。
- **在循环里重复 `re.compile`**：大文件应像 `logstats` 一样模块级编译一次。
- **过度使用正则**：`line.startswith("ERROR")` 或 `line.split()` 有时更清晰；正则适合“格式多变但仍有模式”的日志。
- **混淆 `match` 与 `search`**：`re.match` 只从字符串**开头**匹配；日志行前面有时间戳时通常要用 `search`。

```python run
import re

samples = ["INFO ok", "2026 INFO ok", "2026-INFO ok"]
for line in samples:
    m_match = re.match(r"INFO", line)
    m_search = re.search(r"INFO", line)
    print(line)
    print("  match at start?", bool(m_match))
    print("  search anywhere?", bool(m_search))
    if m_search:
        print("  search span", m_search.span())
```

`match` 只从行首对齐，带时间戳的行会得到 `None`；`search` 能在行内找到 `INFO`。读日志时若级别不在第一列，应优先 `search` 或在模式里写上日期前缀。

## 对照

| 需求 | Python `re` | JavaScript | Java |
|---|---|---|---|
| 首个匹配 | `re.search(p, s)` | `s.match(p)` / `RegExp.exec` | `Pattern.matcher(s).find()` |
| 全部匹配 | `re.findall(p, s)` | `s.matchAll` / `split` | `matcher` 循环 |
| 预编译 | `re.compile(p)` | `new RegExp(p)` | `Pattern.compile(p)` |
| 原始字符串 | `r"\d"` | 无（用 `\\d`） | 字符串 `\\d` |

## 读代码

`logstats.py` 把“从一行日志里认级别”浓缩成两行核心逻辑：

```python
LEVEL_RE = re.compile(r"\b(INFO|WARNING|ERROR|DEBUG)\b")

def parse_lines(text: str) -> Counter[str]:
    counts: Counter[str] = Counter()
    for line in text.splitlines():
        m = LEVEL_RE.search(line)
        if m:
            counts[m.group(1)] += 1
    return counts
```

逐段说明：

1. **`LEVEL_RE` 放在模块顶层**：模式固定，编译一次供所有调用复用；测试 `test_logstats.py` 直接 `from logstats import parse_lines`，也会用到同一模式。
2. **交替 `(INFO|WARNING|...)`**：捕获组 1 就是级别名；`group(1)` 与 `group(0)` 在这里相同，但保留组便于以后在模式里加前缀而仍只取级别。
3. **`\b` 两侧**：要求级别是独立“词”，减少误匹配；若日志格式是 `level=INFO`，需要改成 `level=(INFO|...)` 之类，而不是生搬 `\b`。
4. **`splitlines()`**：比 `split("\n")` 更稳妥，会处理 `\r\n`；空行会跳过（`search` 无匹配）。
5. **`Counter`**：缺省级别不出现；`main` 里按固定顺序打印时还要 `if counts[level]`，避免输出一堆 `0`。

测试用例构造了三行文本，断言 `INFO` 为 2、`ERROR` 为 1——读测试能反推正则应跳过无级别行。

## 练习

### 练习 1：search 命中

```python exercise id=s14-l02-re
# --- starter ---
import re

m = re.search("z", "cat")
# --- solution ---
import re

m = re.search("a", "cat")
# --- check ---
assert m and m.group(0) == "a"
```

### 练习 2：提取温度数字

实现 `first_int(s: str) -> int | None`：用 `re.search(r"\d+", s)` 找第一个整数；找不到返回 `None`。

```python exercise id=s14-l02-int
# --- starter ---
import re

def first_int(s: str) -> int | None:
    return None
# --- solution ---
import re

def first_int(s: str) -> int | None:
    m = re.search(r"\d+", s)
    return int(m.group(0)) if m else None
# --- check ---
assert first_int("temp=22C") == 22
assert first_int("no digits") is None
```

### 练习 3：是否包含 ERROR 级别

实现 `has_error_line(text: str) -> bool`：若任意一行匹配 `\bERROR\b` 则返回 `True`（用 `re.search`，按行扫描）。

```python exercise id=s14-l02-error
# --- starter ---
import re

def has_error_line(text: str) -> bool:
    return False
# --- solution ---
import re

def has_error_line(text: str) -> bool:
    pat = re.compile(r"\bERROR\b")
    return any(pat.search(line) for line in text.splitlines())
# --- check ---
assert has_error_line("INFO ok\nERROR boom\n") is True
assert has_error_line("INFO only\n") is False
```


## 小结

- 日志类任务优先 `search` + 行迭代；时间戳在行首时不要用 `match` 除非从行首写模式。
- 模块级 `re.compile` + 原始字符串是常见工程写法。
- `logstats` 的 `LEVEL_RE` / `parse_lines` 是本阶段正则与 `Counter` 的样板。
- 维护成本上升时，考虑结构化日志（JSON 行）替代自由文本正则。
- 写测试时构造多行 `text` 字符串，比读文件更快定位正则边界问题。
