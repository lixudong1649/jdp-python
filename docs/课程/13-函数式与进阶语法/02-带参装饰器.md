# 13.2 带参装饰器

> 前置：10.2 装饰器、13.1 functools · 约 35 分钟 · 官方对应：[函数定义](https://docs.python.org/zh-cn/3/reference/compound_stmts.html#function-definitions)、[术语：装饰器](https://docs.python.org/zh-cn/3/glossary.html#term-decorator)

## 目标

- 写出三层嵌套：`外层(配置) → decorator(func) → wrapper(*args, **kwargs)`。
- 理解 `@deco(arg)` 等价于 `f = deco(arg)(f)` 的**两次调用**。
- 读懂仅关键字参数 `*` 在装饰器工厂上的用法（如 `retry(*, times=3)`）。
- 能对照阶段项目 `timing.py` 里的 `retry` 实现重试语义与异常传播。

## 核心概念

### 两层 vs 三层

无参装饰器只有两层：`deco(func) → wrapper`。带参时多一层，**最外层先吃配置，再返回真正的装饰器**：

```python run
import functools

def repeat(times: int):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last = None
            for _ in range(times):
                last = func(*args, **kwargs)
            return last
        return wrapper
    return decorator

@repeat(2)
def greet(name: str) -> str:
    return f"hi {name}"

print(greet("py"))
print(repeat(2)(greet)("again"))
```

`@repeat(2)` 时 Python 先执行 `repeat(2)` 得到 `decorator`，再执行 `decorator(greet)` 得到 `wrapper`，最后把名字 `greet` 绑定到 `wrapper`。

### 常见写法：可选参数装饰器

有时希望 `@log` 与 `@log(level="debug")` 都能用，可以用“第一层参数可选”模式（本课了解即可，项目里更推荐显式关键字参数）：

```python run
import functools

def log(_func=None, *, level: str = "info"):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            print(f"[{level}] call {func.__name__}")
            return func(*args, **kwargs)
        return wrapper
    if _func is None:
        return decorator
    return decorator(_func)

@log
def a():
    return 1

@log(level="debug")
def b():
    return 2

print(a(), b())
```

### 重试装饰器：捕获指定异常

与 `timing.py` 同结构的简化版：只重试 `ConnectionError`，次数用尽后抛出最后一次异常：

```python run
import functools

def retry(*, times: int, exc: type[BaseException] = Exception):
    if times < 1:
        raise ValueError("times 至少为 1")

    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exc as e:
                    last = e
                    if attempt == times:
                        break
            assert last is not None
            raise last
        return wrapper
    return decorator

calls = {"n": 0}

@retry(times=3, exc=ConnectionError)
def flaky() -> str:
    calls["n"] += 1
    if calls["n"] < 3:
        raise ConnectionError("抖动")
    return "ok"

print(flaky(), calls)
```

注意 `raise last` 保留原始 traceback 链；若写成 `raise RuntimeError(last)` 会丢失类型信息。

### 叠加顺序回顾

带参装饰器与无参一样：**离 `def` 最近的先应用**：

```python run
import functools

def tag(name):
    def deco(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            return f"<{name}>{func(*args, **kwargs)}</{name}>"
        return wrapper
    return deco

@tag("outer")
@tag("inner")
def word():
    return "x"

print(word())
```

等价于 `word = tag("outer")(tag("inner")(word))`，先包 `inner` 再包 `outer`。

## 易错点

- **少写一层 `return decorator`**：写成 `@retry(times=3)` 却只有两层，会把 `func` 当成 `times`，运行时报 `TypeError`。
- **`@retry` 漏括号**：无参形式下 `retry` 收到的是函数本身，而不是配置；项目里用 `*, times` 强制 `@retry(times=3)` 写法。
- **wrapper 吞掉返回值**：循环重试时忘记 `return func(...)`，成功路径返回 `None`。
- **捕获过宽**：`except Exception` 会把 `KeyboardInterrupt` 以外的几乎所有错误都重试，生产环境应指定异常类型。
- **装饰器在 import 时执行**：`times < 1` 的校验在**定义装饰器时**就运行，不是每次调用函数时。

```python run raises=TypeError
def broken(times):
    def wrapper(func):
        return func
    return wrapper

@broken
def f():
    return 1

print(f())
```

## 对照

| 概念 | Python | TS/JS | Java |
|---|---|---|---|
| 带参语法 | `@deco(cfg)` | `@deco(cfg)` | `@Anno(attr=1)` |
| 调用链 | `deco(cfg)(func)` | 类似 | 注解 + 框架处理 |
| 关键字-only 配置 | `def deco(*, times: int)` | 对象参数 | 注解属性 |
| 典型用途 | 重试、日志级别、路由路径 | 同左 | Spring `@RequestMapping` |

Python 装饰器会**立刻替换**函数对象；Java 注解多数只是元数据，要靠框架扫描。

## 读代码

下面是与仓库一致的阶段项目源码。读的时候按**从外到内**三层拆：

```python source=examples/项目/13-计时重试装饰器/timing.py
"""计时与重试装饰器（阶段 13 项目）。"""
from __future__ import annotations

import functools
import time
from collections.abc import Callable
from typing import TypeVar

F = TypeVar("F", bound=Callable[..., object])


def timed(func: F) -> F:
    @functools.wraps(func)
    def wrapper(*args: object, **kwargs: object) -> object:
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            ms = (time.perf_counter() - start) * 1000
            print(f"{func.__name__} {ms:.2f} ms")

    return wrapper  # type: ignore[return-value]


def retry(*, times: int, exc: type[BaseException] = Exception) -> Callable[[F], F]:
    if times < 1:
        raise ValueError("times 至少为 1")

    def decorator(func: F) -> F:
        @functools.wraps(func)
        def wrapper(*args: object, **kwargs: object) -> object:
            last: BaseException | None = None
            for attempt in range(1, times + 1):
                try:
                    return func(*args, **kwargs)
                except exc as e:
                    last = e
                    if attempt == times:
                        break
            assert last is not None
            raise last

        return wrapper  # type: ignore[return-value]

    return decorator
```

阅读要点：

1. `retry` 的 `*` 表示 `times` 必须以关键字传入，避免与“无参装饰器”写法混淆。
2. `exc` 默认 `Exception` 可配置为 `ConnectionError` 等，缩小重试范围。
3. 循环里**成功就 `return`**，失败则更新 `last`；最后一次仍失败则 `raise last`，而不是包装成新异常。
4. `TypeVar F` 让装饰后的对象在类型检查时仍像原函数；`# type: ignore` 仅给静态检查器看。
5. Web 框架的 `@app.get("/items")` 同样是外层吃路径、内层登记函数；先认三层结构，再读框架语义。

## 练习

### 练习 1：HTML 标签装饰器

实现 `tag(name)`：无参函数被装饰后返回 `"<{name}>" + 原返回值 + "</{name}>"`。

```python exercise id=s13-l02-deco
# --- starter ---
def tag(name):
    def deco(func):
        return func
    return deco
# --- solution ---
import functools

def tag(name):
    def deco(func):
        @functools.wraps(func)
        def wrapper():
            return f"<{name}>{func()}</{name}>"
        return wrapper
    return deco

@tag("b")
def hi():
    return "x"
# --- check ---
assert hi() == "<b>x</b>"
```

### 练习 2：限制调用次数

实现 `call_at_most(times)`：被装饰函数最多成功执行 `times` 次，之后调用抛出 `RuntimeError("too many calls")`。

```python exercise id=s13-l02-limit
# --- starter ---
import functools

def call_at_most(times: int):
    def decorator(func):
        return func
    return decorator
# --- solution ---
import functools

def call_at_most(times: int):
    def decorator(func):
        count = {"n": 0}

        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            if count["n"] >= times:
                raise RuntimeError("too many calls")
            count["n"] += 1
            return func(*args, **kwargs)
        return wrapper
    return decorator
# --- check ---
@call_at_most(2)
def inc(x):
    return x + 1

assert inc(1) == 2
assert inc(2) == 3
try:
    inc(3)
except RuntimeError as e:
    assert "too many" in str(e)
else:
    raise AssertionError("第三次应失败")
```

## 小结

- 带参装饰器：`配置 = 外层(参数)`，`wrapper = 配置(函数)`。
- 模板：外层校验配置 → `decorator(func)` → `@wraps` 的 `wrapper` → `return decorator`。
- `timing.py` 的 `retry` 示范关键字配置、窄异常捕获与 `raise last`。
- 多个装饰器仍从下往上包裹；注册型路由装饰器在 import 时登记。
