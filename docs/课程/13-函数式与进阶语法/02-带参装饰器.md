# 13.2 带参装饰器

> 前置：10.2 装饰器 · 约 25 分钟 · 官方对应：[函数定义](https://docs.python.org/zh-cn/3/reference/compound_stmts.html#function-definitions)

## 目标

- 写出三层嵌套的带参装饰器
- 理解 `@deco(arg)` 的两次调用

## 核心概念

```python run
import functools

def repeat(times: int):
    def deco(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            out = None
            for _ in range(times):
                out = func(*args, **kwargs)
            return out
        return wrapper
    return deco

@repeat(2)
def greet(name: str) -> str:
    return f"hi {name}"

print(greet("py"))
```

## 易错点

- 少一层嵌套会把装饰器参数当成被装饰函数。
- 多个装饰器从下往上包裹。

## 练习

```python exercise id=s13-l02-deco
# --- starter ---
def tag(name):
    def deco(func):
        return func
    return deco
# --- solution ---
def tag(name):
    def deco(func):
        def wrapper():
            return f"<{name}>" + func() + f"</{name}>"
        return wrapper
    return deco

@tag("b")
def hi():
    return "x"
# --- check ---
assert hi() == "<b>x</b>"
```

## 小结

- 带参装饰器先调用外层
- 内层才是 classic decorator
