# 15.4 覆盖率概念

> 前置：15.1 pytest 基础 · 约 25 分钟 · 官方对应：[pytest-cov 说明](https://docs.pytest.org/en/stable/)

## 目标

- 知道覆盖率是信号不是 KPI
- 优先覆盖分支与错误路径

## 核心概念

```python run
def safe_div(a, b):
    if b == 0:
        raise ValueError("zero")
    return a / b

try:
    safe_div(1, 0)
except ValueError:
    pass
else:
    raise AssertionError
```

## 易错点

- 100% 覆盖率仍可能漏测语义。
- 不要为覆盖率写无断言测试。

## 练习

```python exercise id=s15-l04-cov
# --- starter ---
def sign(x):
    return 0
# --- solution ---
def sign(x):
    return (x > 0) - (x < 0)
# --- check ---
assert sign(3) == 1 and sign(-1) == -1
```

## 小结

- 覆盖错误路径
- 测试应表达期望行为
