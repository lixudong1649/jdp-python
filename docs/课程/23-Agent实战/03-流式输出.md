# 23.3 流式输出

> 前置：10.1 生成器 · 约 25 分钟 · 官方对应：[迭代器](https://docs.python.org/zh-cn/3/tutorial/classes.html#iterators)

## 目标

- 理解 stream 迭代 partial 响应
- 终端打印与累积完整消息

## 核心概念

```python run
def stream():
    for chunk in ("你", "好"):
        yield chunk

print("".join(stream()))
```

## 易错点

- 流式下 tool call 可能分片到达。
- 需要缓冲拼完整 JSON。

## 练习

```python exercise id=s23-l03-stream
# --- starter ---
def stream():
    return iter([])
# --- solution ---
def stream():
    yield 'a'
# --- check ---
assert list(stream()) == ['a']
```
