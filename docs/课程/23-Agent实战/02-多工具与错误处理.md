# 23.2 多工具与错误处理

> 前置：23.1 工具协议 · 约 35 分钟 · 官方对应：[错误和异常](https://docs.python.org/zh-cn/3/tutorial/errors.html) · 核对日期 2026-10-18

## 目标

- 在一个 Agent 回合里处理 **多个 tool_use** 块：顺序执行、收集结果、再一次性追加到 `messages`。
- 用 **try/except** 把工具异常变成模型可读的 `tool_result` 文本，避免整轮崩溃。
- 记录足够日志（工具名、参数摘要）便于排查，不把堆栈直接展示给终端用户。
- 扩展 `mini_agent` 注册多个工具，并保持 `run_tool` 行为一致。

## 核心概念

### 单工具异常包装

```python run
def run_tool(name: str, reg: dict, **kw):
    try:
        return reg[name](**kw)
    except KeyError:
        return f"错误：未知工具 {name}"
    except Exception as e:
        return f"错误：{type(e).__name__}: {e}"

reg = {"echo": lambda text: text}
print(run_tool("echo", reg, text="ok"))
print(run_tool("nope", reg))
```

### 多工具顺序执行

```python run
calls = [
    ("echo", {"text": "a"}),
    ("echo", {"text": "b"}),
]

def execute_all(reg, calls):
    out = []
    for name, kw in calls:
        out.append(reg[name](**kw))
    return out

reg = {"echo": lambda text: text}
print(execute_all(reg, calls))
```

### 静态：多工具注册

```python
from mini_agent.tools import tool, REGISTRY

@tool("add")
def add(a: int, b: int) -> int:
    return a + b

@tool("echo")
def echo(text: str) -> str:
    return text

# REGISTRY 现在含 add 与 echo
```

### 课内可运行：失败工具

```python run
def fail_tool():
    raise ValueError("bad input")

def safe_call(fn):
    try:
        return fn()
    except ValueError as e:
        return {"error": str(e)}

print(safe_call(fail_tool))
```


## 易错点

- **裸 `raise` 到 Agent 顶层**：用户只看到崩溃；应捕获并写入 `tool_result`。
- **泄露密钥或路径**：错误消息里不要带 `.env` 内容、绝对路径。
- **忽略部分失败**：一个工具失败时，其他工具结果仍应写回历史。
- **无限重试工具**：对 `ConnectionError` 可限次重试（见 10.2 装饰器），不要死循环。

```python run raises=ZeroDivisionError
def divide(a, b):
    return a / b

divide(1, 0)
```

## 读代码

`minimal_agent.py` 主循环在工具执行处应包一层异常处理（读仓库时搜索 `TOOL_FUNCTIONS` 调用）。阶段 23 包保持 **`run_tool` 严格**：未知名 `KeyError`，由上层 Agent 捕获：

```python
from __future__ import annotations

from mini_agent.tools import REGISTRY


def run_tool(name: str, **kwargs: object) -> object:
    if name not in REGISTRY:
        raise KeyError(name)
    return REGISTRY[name](**kwargs)
```

上层可写成：

```python
def run_tool_safe(name: str, **kwargs):
    try:
        return run_tool(name, **kwargs)
    except KeyError:
        return f"未注册工具: {name}"
    except Exception as exc:
        return f"工具执行失败: {exc}"
```

## 练习

### 练习 1：safe 除法

```python exercise id=s23-l02-err
# --- starter ---
def safe(x):
    return x
# --- solution ---
def safe(x):
    try:
        return 1 / x
    except ZeroDivisionError:
        return None
# --- check ---
assert safe(0) is None
assert safe(2) == 0.5
```

### 练习 2：批量执行带错误收集

```python exercise id=s23-l02-batch
# --- starter ---
def run_batch(reg, calls):
    return []
# --- solution ---
def run_batch(reg, calls):
    results = []
    for name, kw in calls:
        try:
            results.append(reg[name](**kw))
        except Exception as e:
            results.append(str(e))
    return results
# --- check ---
reg = {"ok": lambda: 1, "bad": lambda: (_ for _ in ()).throw(ValueError("x"))}
out = run_batch(reg, [("ok", {}), ("bad", {})])
assert out[0] == 1
assert "x" in out[1]
```

- 多工具 = 多次 `run_tool` + 结果列表；异常应转成文本喂回模型。
- `mini_agent.run_tool` 故意严格；Agent 层做 `safe` 包装。
- 读 minimal_agent 与 `runner.py` 对照职责分界。
