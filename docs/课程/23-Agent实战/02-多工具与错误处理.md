# 23.2 多工具与错误处理

> 前置：23.1 工具协议 · 约 25 分钟 · 官方对应：[异常](https://docs.python.org/zh-cn/3/tutorial/errors.html)

## 目标

- 工具执行 try/except 回传错误
- 并行 tool call 需合并结果

## 核心概念

```python run
def run_tool(name, **kw):
    if name == "fail":
        raise ValueError("bad")
    return name

try:
    run_tool("fail")
except ValueError as e:
    print(str(e))
```

## 易错点

- 把异常直接抛给用户不友好。
- 记录日志便于排查。

## 读代码

Agent 循环里应对 SDK/工具异常做分支，避免整轮崩溃。

## 练习

```python exercise id=s23-l02-err
# --- starter ---
def safe(x):
    return x
# --- solution ---
def safe(x):
    try:
        return 1/x
    except ZeroDivisionError:
        return None
# --- check ---
assert safe(0) is None
```

## 小结

- 错误应变成模型可读消息
- 不要裸 raise 到顶层
