# 23.1 工具调用协议

> 前置：11. minimal_agent · 约 25 分钟 · 官方对应：[Anthropic 消息 API](https://docs.python.org/zh-cn/3/tutorial/index.html)

## 目标

- 理解 tools 列表与 tool_use 块
- TOOL_FUNCTIONS 映射 name→callable

## 核心概念

```python run
TOOLS = {"get_weather": lambda city: f"{city}:晴"}
name = "get_weather"
print(TOOLS[name]("上海"))
```

## 易错点

- 工具 schema 要与函数参数一致。
- 未注册 name 会 KeyError。
