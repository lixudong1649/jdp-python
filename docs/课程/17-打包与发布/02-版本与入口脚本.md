# 17.2 版本与入口脚本

> 前置：5.2 包 · 约 25 分钟 · 官方对应：[entry points](https://packaging.python.org/en/latest/specifications/entry-points/)

## 目标

- 在 pyproject 声明 console_scripts
- 模块内写 main()

## 核心概念

```python run
def main() -> int:
    print("cli")
    return 0

raise SystemExit(main())
```

## 易错点

- 入口函数应返回 int exit code。
- 可编辑安装后命令在 .venv/bin。
