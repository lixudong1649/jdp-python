# 12.1 特殊方法全景

> 前置：7.2 继承与特殊方法 · 约 25 分钟 · 官方对应：[数据模型](https://docs.python.org/zh-cn/3/reference/datamodel.html#special-method-names)

## 目标

- 列出常见特殊方法及其对应的内置语法
- 实现 `__repr__` 与 `__eq__` 便于调试与比较
- 理解特殊方法由解释器自动调用，不要手动加括号当普通方法

## 核心概念

特殊方法（dunder）让对象参与内置操作：

```python run
class Point:
    def __init__(self, x: int, y: int) -> None:
        self.x, self.y = x, y

    def __repr__(self) -> str:
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)

p = Point(1, 2)
print(p, p == Point(1, 2))
```

## 易错点

- 只写 `__eq__` 不写 `__hash__` 时实例默认不可哈希。
- `__repr__` 必须返回 str，否则 `TypeError`。

```python run raises=TypeError
class Bad:
    def __repr__(self):
        return 123

print(repr(Bad()))
```


## 对照

| 概念 | Python | JS | Java |
|---|---|---|---|
| 字符串表示 | `__repr__` | 无标准 | `toString()` |
| 相等 | `__eq__` | `===` | `equals()` |

## 读代码

SDK 模型类依赖 `__repr__` 让 `print(resp)` 可读；读代码时看到 `repr(x)` 或日志里的对象，想到类里是否实现了 `__repr__`。

## 练习

```python exercise id=s12-l01-repr
# --- starter ---
class Tag:
    def __init__(self, name):
        self.name = name
# --- solution ---
class Tag:
    def __init__(self, name):
        self.name = name

    def __repr__(self):
        return f"Tag(name={self.name!r})"
# --- check ---
t = Tag("py")
assert repr(t) == "Tag(name='py')"
```

## 小结

- 特殊方法连接对象与内置语法
- `__repr__` 面向开发者调试
- `__eq__` 定义值相等
