# 12.1 特殊方法全景

> 前置：7.2 继承与特殊方法 · 约 35 分钟 · 官方对应：[数据模型 · 特殊方法名称](https://docs.python.org/zh-cn/3/reference/datamodel.html#special-method-names)

## 目标

- 把常见内置操作（`print`、`==`、`len`、索引、`in`）映射到对应的双下划线方法。
- 为自定义类实现 `__repr__` 与 `__eq__`，让调试与集合行为可预期。
- 理解特殊方法由解释器在语法背后调用，业务代码里不要写成 `obj.__eq__(other)` 除非你在写框架。
- 知道只定义 `__eq__` 时默认 `__hash__` 会变为 `None`，实例不能放进 `set`/`dict` 键。

## 核心概念

### 双下划线方法是什么

特殊方法（dunder，double underscore）让**用户定义的类型**参与 Python 已有的语法。它们不是“魔法”，只是约定好的钩子：解释器在执行 `len(x)` 时等价于调用 `type(x).__len__(x)`（并可能走 `__index__` 等分支）。

```python run
class Size:
    def __init__(self, n: int) -> None:
        self.n = n

    def __len__(self) -> int:
        return self.n

    def __repr__(self) -> str:
        return f"Size({self.n})"

s = Size(3)
print(len(s), repr(s), s)          # print 会调用 __str__，没有则用 __repr__
```

读别人的类时，看到 `for`、`with`、`+` 等运算符，先在脑子里问：**对应哪个 dunder？** 答案几乎总能在[数据模型](https://docs.python.org/zh-cn/3/reference/datamodel.html)里查到。

### `__repr__` 与 `__str__`

- `repr(obj)` / 交互式回显 → `__repr__`，应尽量**无歧义**，理想形态像能 `eval` 的构造表达式。
- `str(obj)` / `print(obj)` → 先找 `__str__`，没有则退回 `__repr__`。

```python run
class Tag:
    def __init__(self, name: str) -> None:
        self.name = name

    def __repr__(self) -> str:
        return f"Tag(name={self.name!r})"

    def __str__(self) -> str:
        return self.name

t = Tag("py")
print(repr(t), str(t))
```

日志与单步调试里，`repr` 比 `str` 更常出现；SDK 的响应对象往往实现 `__repr__`，这样 `print(resp)` 不会只显示内存地址。

### `__eq__` 与 `NotImplemented`

`==` 调用 `__eq__`。若类型不兼容，应返回 `NotImplemented`，让解释器尝试对方类型的比较逻辑；不要对未知类型直接 `return False`，否则会截断对称比较。

```python run
class Point:
    def __init__(self, x: int, y: int) -> None:
        self.x, self.y = x, y

    def __repr__(self) -> str:
        return f"Point({self.x}, {self.y})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Point):
            return NotImplemented
        return (self.x, self.y) == (other.x, other.y)

p = Point(1, 2)
print(p == Point(1, 2), p == (1, 2))   # 后者走 tuple 的 __eq__，结果为 False
```

自定义类放进 `list` 后调用 `sort` 或 `min` 时，若只实现了 `__eq__` 而没有全序关系，可能还需要 `__lt__` 等；本课只强调相等性。

### 常见特殊方法速查（本阶段会反复见到）

| 语法 / 内置 | 特殊方法 | 本课后续 |
|---|---|---|
| `len(x)` | `__len__` | 12.2 迭代、`RingBuffer` |
| `x[i]` | `__getitem__` | 12.2 |
| `x in y` | `__contains__` | 12.2 |
| `for v in x` | `__iter__`（或 `__getitem__` 连续整数索引） | 12.2 |
| `x == y` | `__eq__` | 本课 |
| `print(x)` | `__str__` / `__repr__` | 本课 |

容器类往往一次实现多个方法，让它们像内置 `list` 一样好用；阶段 12 项目里的环形缓冲区就是样板。

```python run
class Pair:
    def __init__(self, a: int, b: int) -> None:
        self.a, self.b = a, b

    def __repr__(self) -> str:
        return f"Pair({self.a}, {self.b})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Pair):
            return NotImplemented
        return self.a == other.a and self.b == other.b

    def __hash__(self) -> int:
        return hash((self.a, self.b))

p = Pair(1, 2)
print({p: "ok"}[Pair(1, 2)])
```

若你定义了 `__eq__` 且希望实例可哈希，需要**同时**实现一致的 `__hash__`（核对日期 2026-10-18：行为与 [object.__hash__](https://docs.python.org/zh-cn/3/reference/datamodel.html#object.__hash__) 文档一致；项目使用 Python 3.12，当前稳定版为 3.15）。


## 易错点

- **把 dunder 当普通方法调用**：`p.__repr__()` 能跑，但可读性差；调试时用 `repr(p)`，让团队习惯与内置类型一致。
- **只写 `__eq__` 却想当 dict 键**：未定义 `__hash__` 时，用户类在定义 `__eq__` 后 `__hash__` 自动设为 `None`，`{obj: 1}` 会失败。
- **`__repr__` 必须返回 `str`**：返回 `int` 会在 `repr()` 时触发 `TypeError`。
- **`__eq__` 对不相关类型返回 `False`**：应返回 `NotImplemented`，否则 `Point(1,1) == (1,1)` 等对称比较结果可能违反预期。

```python run raises=TypeError
class BadRepr:
    def __repr__(self):
        return 42

repr(BadRepr())
```

```python run raises=TypeError
class NoHash:
    def __eq__(self, other: object) -> bool:
        return True

{NoHash(): 1}
```

## 对照

| 概念 | Python | JS | Java |
|---|---|---|---|
| 调试字符串 | `__repr__` / `repr()` | 无统一标准，常手写 `toJSON` | `toString()` |
| 展示字符串 | `__str__` / `print` | `String(obj)` 或模板 | `toString()` 可被重写 |
| 相等 | `__eq__` / `==` | `===`（值+类型） | `equals(Object)` |
| 可哈希 | `__hash__`（与 `__eq__` 一致） | 无内置 dict 键语义 | `hashCode()` + `equals` 契约 |
| 长度 | `__len__` | `.length`（数组） | `size()` / `length` |

Python 的 `==` 默认走 `__eq__`，而 `is` 比较对象标识；Java 的 `==` 对引用类型是比较引用，容易和 Python 混淆。

## 读代码

下面摘自 `examples/项目/12-自定义容器类/ring_buffer.py`，展示容器如何把多项特殊方法拼在一起（节选连续 12 行）：

```python fragment
    def __len__(self) -> int:
        return self._size

    def __getitem__(self, index: int) -> object:
        if not isinstance(index, int):
            raise TypeError("索引必须是 int")
        if index < 0:
            index += self._size
        if index < 0 or index >= self._size:
            raise IndexError(index)
        return self._data[(self._start + index) % self._cap]

    def __contains__(self, item: object) -> bool:
```

- 第 1–2 行：`__len__` 让 `len(buf)` 返回逻辑元素个数 `_size`，而不是底层数组容量 `_cap`。
- 第 4 行：`__getitem__` 是 `buf[i]` 的入口，类型注解里的 `index: int` 仅作提示，运行时不强制。
- 第 5–6 行：非 `int` 索引立刻 `TypeError`，比默默失败更易排查。
- 第 7–8 行：支持负索引，先加上 `_size` 转成从 0 起的逻辑下标。
- 第 9–10 行：越界抛 `IndexError`，与内置 `list` 一致。
- 第 11 行：物理下标用 `(self._start + index) % self._cap` 映射到环形槽位。
- 第 13 行：`__contains__` 服务 `item in buf`，后面通常会遍历逻辑区间而不是整个 `_data`。

读项目代码时，先圈出实现了哪些 dunder，再对照你是否需要同样的语义（尤其是边界与异常类型）。

## 练习

### 练习 1：实现 `__repr__`

为 `Tag` 实现无歧义的 `__repr__`。

```python exercise id=s12-l01-repr
# --- starter ---
class Tag:
    def __init__(self, name):
        self.name = name
# --- solution ---
class Tag:
    def __init__(self, name):
        self.name = name

    def __repr__(self):
        return f"Tag(name={self.name!r})"
# --- check ---
t = Tag("py")
assert repr(t) == "Tag(name='py')"
```

### 练习 2：实现 `__eq__` 与一致的 `__hash__`

`Coord` 用整数 `x, y` 表示坐标；相等则哈希相同，以便放入 `set`。

```python exercise id=s12-l01-eq-hash
# --- starter ---
class Coord:
    def __init__(self, x: int, y: int) -> None:
        self.x = x
        self.y = y

    def __repr__(self) -> str:
        return f"Coord({self.x}, {self.y})"
# --- solution ---
class Coord:
    def __init__(self, x: int, y: int) -> None:
        self.x = x
        self.y = y

    def __repr__(self) -> str:
        return f"Coord({self.x}, {self.y})"

    def __eq__(self, other: object) -> bool:
        if not isinstance(other, Coord):
            return NotImplemented
        return self.x == other.x and self.y == other.y

    def __hash__(self) -> int:
        return hash((self.x, self.y))
# --- check ---
a, b = Coord(1, 2), Coord(1, 2)
assert a == b
assert len({a, b}) == 1
assert Coord(1, 2) != (1, 2)
```

## 小结

- 特殊方法把内置语法接到你的类上；查表时以[数据模型](https://docs.python.org/zh-cn/3/reference/datamodel.html)为准。
- `repr` 面向开发者，`str` 面向最终读者；`print` 优先 `__str__`。
- `__eq__` 配 `NotImplemented`；若要可哈希，显式实现与相等一致的 `__hash__`。
- 读容器类：从 `__len__`、`__getitem__`、`__contains__` 看清边界语义。
