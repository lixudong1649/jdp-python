# 12.2 迭代协议

> 前置：10.1 迭代器与生成器 · 约 25 分钟 · 官方对应：[迭代器协议](https://docs.python.org/zh-cn/3/c-api/iter.html)

## 目标

- 实现 `__iter__`/`__next__` 或委托给内部容器
- 让类支持 `for` 与 `iter()`
- 区分可迭代对象与迭代器

## 核心概念

容器类通常实现 `__iter__` 返回迭代器：

```python run
class Countdown:
    def __init__(self, start: int) -> None:
        self.start = start

    def __iter__(self):
        n = self.start
        while n > 0:
            yield n
            n -= 1

print(list(Countdown(3)))
```

## 易错点

- 只实现 `__getitem__` 不能自动支持 `for`（除非配合 `collections.abc.Sequence`）。
- 迭代器耗尽后需重新创建。

## 对照

| | Python | JS | Java |
|---|---|---|---|
| 协议 | `__iter__` | `Symbol.iterator` | `Iterable` |

## 读代码

`for block in resp.content` 依赖 content 是可迭代对象；读 SDK 时查返回类型是否实现了序列或自定义迭代。

## 练习

```python exercise id=s12-l02-iter
# --- starter ---
class Two:
    def __init__(self, a, b):
        self.a, self.b = a, b
# --- solution ---
class Two:
    def __init__(self, a, b):
        self.a, self.b = a, b

    def __iter__(self):
        yield self.a
        yield self.b
# --- check ---
assert list(Two(1, 2)) == [1, 2]
```

## 小结

- `for` 调用 iter/ next 协议
- 生成器函数是简洁的 `__iter__` 实现
