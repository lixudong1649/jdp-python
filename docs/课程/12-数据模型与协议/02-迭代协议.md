# 12.2 迭代协议

> 前置：10.1 迭代器与生成器 · 约 35 分钟 · 官方对应：[迭代器类型](https://docs.python.org/zh-cn/3/c-api/iter.html)、[类作为迭代器](https://docs.python.org/zh-cn/3/tutorial/classes.html#iterators)

## 目标

- 区分**可迭代对象**（有 `__iter__` 或序列协议）与**迭代器**（同时有 `__iter__` 和 `__next__`）。
- 在自定义容器上实现 `__iter__`，让 `for`、`list()`、`sum()` 等内置消费逻辑复用。
- 会用生成器函数（`yield`）作为 `__iter__` 的简洁实现。
- 读懂 `collections.abc.Iterable` / `Iterator` 在类型标注里的含义（核对日期 2026-10-18：项目 Python 3.12，稳定版 3.15；`collections.abc` 自 3.3 起推荐于 `collections`）。

## 核心概念

### `for` 背后发生了什么

`for x in obj:` 大致等价于：

1. `it = iter(obj)` → 调用 `type(obj).__iter__(obj)`；
2. 反复 `next(it)` → 调用 `type(it).__next__(it)`，直到 `StopIteration`。

```python run
class Three:
    def __iter__(self):
        yield 1
        yield 2
        yield 3

it = iter(Three())
print(next(it), next(it), list(it))
```

生成器函数定义的 `__iter__` 每次 `iter(obj)` 都会**新建**一个生成器，因此可以多次遍历；若类本身实现 `__next__` 把自己当迭代器，耗尽后需要重新 `iter()`。

### 可迭代对象 vs 迭代器

| 角色 | 典型方法 | `iter(x)` 返回 |
|---|---|---|
| 可迭代对象 | `__iter__` → 迭代器 | 新迭代器 |
| 迭代器 | `__iter__` 返回 self，`__next__` 产出元素 | 通常 self |

```python run
class Counter:
    def __init__(self, n: int) -> None:
        self.n = n

    def __iter__(self):
        self._i = 0
        return self

    def __next__(self):
        if self._i >= self.n:
            raise StopIteration
        self._i += 1
        return self._i

c = Counter(2)
print(list(c), list(Counter(2)))
```

第二种写法把**容器与迭代状态**绑在同一对象上，容易在嵌套循环里踩坑；容器类更常见的是 `__iter__` 里 `yield`，或返回独立的迭代器对象。

### 序列协议：`__getitem__` 与迭代

若没有 `__iter__`，解释器会尝试用 `__getitem__(0, 1, 2, …)` 模拟迭代，直到 `IndexError`。自定义类若只实现整数索引的 `__getitem__`，也能被 `for` 消费，但不如显式 `__iter__` 清晰。

```python run
class Evens:
    def __init__(self, stop: int) -> None:
        self.stop = stop

    def __getitem__(self, i: int) -> int:
        v = i * 2
        if v >= self.stop:
            raise IndexError
        return v

print(list(Evens(6)))
```

阶段 12 的 `RingBuffer` 同时提供 `__getitem__` 与 `__iter__`，`for` 走 `__iter__` 路径，逻辑更直观。

### 委托给内部容器

包装类最常见模式：`__iter__` 直接 `return iter(self._items)`，或 `yield from self._items`。

```python run
class ReadonlyList:
    def __init__(self, items: list[int]) -> None:
        self._items = list(items)

    def __len__(self) -> int:
        return len(self._items)

    def __iter__(self):
        yield from self._items

print(sum(ReadonlyList([1, 2, 3])))
```

```python run
class Ring:
```

## 易错点

- **把迭代器当可迭代对象重复使用**：列表可以多次 `for`，但 `iter([1,2])` 返回的 list_iterator 耗尽后不会自动重置。
- **在 `__iter__` 里忘记 `return self`（当类即迭代器时）**：`for` 拿到 `None` 会在第一次 `next` 时报错。
- **生成器 `__iter__` 与可变容器**：若在迭代过程中修改底层结构，行为取决于你是否拷贝快照；RingBuffer 在 `append` 时移动头指针，迭代时应基于逻辑长度。
- **混淆 `StopIteration` 与 `return` 在生成器里**：生成器里 `return` 会触发 `StopIteration` 并附带返回值（调用方通常用 `yield from` 获取）。

```python run raises=TypeError
class Broken:
    def __iter__(self):
        pass

list(Broken())
```

## 对照

| 概念 | Python | JS | Java |
|---|---|---|---|
| 获取迭代器 | `iter(obj)` / `obj.__iter__()` | `obj[Symbol.iterator]()` | `iterator()` |
| 下一项 | `next(it)` / `__next__` | `it.next()` | `next()` |
| 结束信号 | `StopIteration` | `{done: true}` | `NoSuchElementException` |
| 简洁实现 | 生成器 `yield` | `function*` | `Stream` / 手动 `Iterator` |
| 只读遍历 API | `for x in xs` | `for (const x of xs)` | `for (T x : xs)` 需 `Iterable` |

## 读代码

`examples/agent/minimal_agent.py` 里模型响应 `resp.content` 是**块序列**，SDK 把它做成可迭代对象，因此可以用 `for block in resp.content` 逐项处理工具调用：

```python fragment
    if resp.stop_reason != "tool_use":
        final_text = "".join([b.text for b in resp.content if b.type == "text"])
        print(f"[第 {turn} 轮] 最终回答：{final_text}")
        break

    # 3) 执行模型请求的每个工具，把结果按 tool_use_id 对应起来
    results = []
    for block in resp.content:
        if block.type == "tool_use":
            output = TOOL_FUNCTIONS[block.name](**block.input)
            print(f"[第 {turn} 轮] 调用工具 {block.name}({block.input}) -> {output}")
            results.append(
                {"type": "tool_result", "tool_use_id": block.id, "content": output}
            )
```

- 第 1 行：根据 `stop_reason` 分支，不是 `tool_use` 说明模型已给出文本答案。
- 第 2 行：列表推导遍历 `resp.content`，只拼接 `type == "text"` 的块——响应是**异构块**的迭代，不是纯字符串。
- 第 3 行：打印轮次与最终文本后 `break` 结束外层 `for turn`。
- 第 6 行：进入工具分支时先准备 `results` 列表，稍后作为下一轮 `messages` 的 user 内容。
- 第 7–8 行：显式 `for block in resp.content`，与上一行的推导共享同一迭代协议。
- 第 9 行：用 `block.type` 区分文本块与 `tool_use` 块，类型字段是 SDK 约定。
- 第 10 行：按名字查 `TOOL_FUNCTIONS`，`**block.input` 把 JSON 参数解包成关键字参数。
- 第 11 行：日志展示工具名、入参与返回值，便于本地调试 Agent 循环。
- 第 12–14 行：构造 `tool_result` 字典，必须带上 `tool_use_id` 与模型请求对应。

读 SDK 时：看到 `for x in resp.something`，先确认 `something` 是 list 还是自定义可迭代类型，再查元素有哪些 `type` 字段。

环形缓冲区侧的迭代实现（`ring_buffer.py`）：

```python run
class MiniRing:
    def __init__(self, items):
        self._items = list(items)

    def __getitem__(self, i: int):
        return self._items[i]

    def __iter__(self):
        for i in range(len(self._items)):
            yield self[i]

print(list(MiniRing([10, 20])))
```

## 练习

### 练习 1：双元素可迭代

让 `Two` 支持 `list(Two(1, 2)) == [1, 2]`。

```python exercise id=s12-l02-iter
# --- starter ---
class Two:
    def __init__(self, a, b):
        self.a, self.b = a, b
# --- solution ---
class Two:
    def __init__(self, a, b):
        self.a, self.b = a, b

    def __iter__(self):
        yield self.a
        yield self.b
# --- check ---
assert list(Two(1, 2)) == [1, 2]
```

### 练习 2：范围迭代器（多行逻辑）

实现 `Range(start, stop)`：`stop` 不包含在内；`__iter__` 用 `yield` 产出 `start .. stop-1`。若 `start >= stop`，产出空序列。

```python exercise id=s12-l02-range
# --- starter ---
class Range:
    def __init__(self, start: int, stop: int) -> None:
        self.start = start
        self.stop = stop
# --- solution ---
class Range:
    def __init__(self, start: int, stop: int) -> None:
        self.start = start
        self.stop = stop

    def __iter__(self):
        n = self.start
        while n < self.stop:
            yield n
            n += 1
# --- check ---
assert list(Range(2, 5)) == [2, 3, 4]
assert list(Range(5, 5)) == []
assert sum(Range(0, 3)) == 3
```

## 小结

- `for` = `iter` + 反复 `next`，结束于 `StopIteration`。
- 容器优先写 `__iter__`（常用 `yield`）；序列类可辅以 `__getitem__`。
- 迭代器耗尽要重新 `iter()`；不要把“可多次遍历”误当成迭代器本身的性质。
- 读 Agent / SDK：把 `content` 当成块的可迭代序列，用 `type` 字段分支。
