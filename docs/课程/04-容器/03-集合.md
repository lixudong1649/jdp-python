# 4.3 集合

> 前置：4.2 · 约 15 分钟 · 官方对应：[集合](https://docs.python.org/zh-cn/3/tutorial/datastructures.html#sets)、[集合类型](https://docs.python.org/zh-cn/3/library/stdtypes.html#set-types-set-frozenset)

## 目标

- 用 set 去重和做快速成员判断。
- 掌握并集、交集、差集、对称差。
- 知道 `{}` 是空字典，空集合写 `set()`；了解 `frozenset`。

## 核心概念

### 创建与基本操作

集合是**无序、元素唯一**的容器，元素必须可哈希。

```python run
tags = {"python", "agent", "python"}   # 重复元素自动去掉
print(tags, len(tags))
tags.add("sdk")
tags.discard("not-exist")               # 不存在也不报错；remove 会抛 KeyError
print("agent" in tags)                  # 成员判断：平均 O(1)

empty = set()                           # 注意：{} 是空 dict
print(type(empty), type({}))
print(set([3, 1, 3, 2]))                # 从可迭代对象创建
```

### 集合运算

```python run
required = {"city", "date"}
provided = {"city", "unit"}

print(required | provided)   # 并集
print(required & provided)   # 交集
print(required - provided)   # 差集：必填但没提供
print(required ^ provided)   # 对称差：只在一边出现
print({"city"} <= provided)  # 子集判断
```

### 保序去重

set 不保证顺序。需要“去重但保持首次出现顺序”时，利用 dict 的插入顺序：

```python run
names = ["get_weather", "get_time", "get_weather"]
print(list(dict.fromkeys(names)))   # ['get_weather', 'get_time']
```

### frozenset

`frozenset` 是不可变集合，可哈希，可以作为 dict 的键或放进另一个集合。读码时偶尔见到 `ALLOWED = frozenset({...})` 表示“不可修改的常量集合”。

```python run
ALLOWED_ROLES = frozenset({"user", "assistant"})
print("system" in ALLOWED_ROLES)
```

## 易错点

- **`{}` 不是空集合**，是空字典。
- **依赖 set 的顺序**：打印顺序可能每次运行不同（字符串哈希随机化），不要据此写逻辑或测试。
- **放入不可哈希元素**：`{[1, 2]}` 抛 `TypeError`。
- **`remove` 不存在的元素**抛 `KeyError`，用 `discard` 更安全。

```python run raises=TypeError
s = {["city"]}
```

## 对照

| 操作 | Python | JS | Java |
|---|---|---|---|
| 创建 | `{1, 2}` / `set()` | `new Set([1, 2])` | `Set.of(1, 2)` / `new HashSet<>()` |
| 添加 | `s.add(x)` | `s.add(x)` | `s.add(x)` |
| 包含 | `x in s` | `s.has(x)` | `s.contains(x)` |
| 并 / 交 / 差 | `a \| b`、`a & b`、`a - b` | `a.union(b)` 等（ES2025） | `addAll` / `retainAll` / `removeAll` |

## 读代码

校验模型返回的工具参数是否齐全，是集合运算的典型场景：

```python
schema = tools[0]["input_schema"]
missing = set(schema["required"]) - set(block.input)   # set(dict) 得到键的集合
if missing:
    raise ValueError(f"缺少参数：{sorted(missing)}")
```

`minimal_agent.py` 没有做这类校验（README 中“限制”一节已说明）；11.2 的改造练习会补上。

## 练习

### 练习 1：缺失的必填参数

实现 `missing_params(schema, tool_input)`：返回 `schema["required"]` 中、但 `tool_input`（dict）里没有的键，**按字母序排序后的列表**。

```python exercise id=s04-l03-missing
# --- starter ---
def missing_params(schema, tool_input):
    return []
# --- solution ---
def missing_params(schema, tool_input):
    return sorted(set(schema.get("required", [])) - set(tool_input))
# --- check ---
schema = {"type": "object", "properties": {}, "required": ["city", "date"]}
assert missing_params(schema, {"city": "上海"}) == ["date"]
assert missing_params(schema, {}) == ["city", "date"]
assert missing_params(schema, {"city": "a", "date": "b", "x": 1}) == []
assert missing_params({"type": "object"}, {}) == [], "没有 required 时视为无必填参数"
```

### 练习 2：保序去重

实现 `unique_in_order(items)`：去重并保持首次出现顺序。

```python exercise id=s04-l03-unique
# --- starter ---
def unique_in_order(items):
    return list(set(items))
# --- solution ---
def unique_in_order(items):
    return list(dict.fromkeys(items))
# --- check ---
assert unique_in_order(["b", "a", "b", "c", "a"]) == ["b", "a", "c"]
assert unique_in_order([3, 1, 3, 2, 1]) == [3, 1, 2]
assert unique_in_order([]) == []
```

## 小结

- set：无序、唯一、成员判断快；空集合写 `set()`。
- `|` `&` `-` `^` 对应并、交、差、对称差。
- 保序去重用 `dict.fromkeys`。
