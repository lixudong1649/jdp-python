# 阶段 4 · 容器

**达成标志**：给你一个嵌套的 list/dict 结构，能写出任意值的访问路径，能读懂推导式。这是读懂真实代码最关键的一步——数据大多以容器形式流动。

| 课程 | 你将学会 |
|---|---|
| [4.1 列表、元组与切片](01-列表元组与切片.md) | list 增删改查、排序、复制；tuple 与解包；切片完整规则 |
| [4.2 字典](02-字典.md) | 增删改查、`get`/`setdefault`、遍历、合并、嵌套结构访问路径 |
| [4.3 集合](03-集合.md) | 去重、成员判断、并交差 |
| [4.4 推导式与解包](04-推导式与解包.md) | 列表/字典/集合推导式、生成器表达式、`*` 与 `**` 解包合并 |

**与终点的关系**：`PROVIDERS`（两层 dict）、`tools`（list 中嵌套 dict）、`messages`（不断追加的对话历史）以及 `[b.text for b in resp.content if b.type == "text"]` 都在本阶段讲清。
