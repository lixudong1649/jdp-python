# 20.2 复杂度与数据结构

> 前置：4. 容器 · 约 25 分钟 · 官方对应：[时间复杂度](https://docs.python.org/zh-cn/3/tutorial/datastructures.html)

## 目标

- 知道 list vs set 成员检测差异
- 避免嵌套循环爆炸

## 核心概念

```python run
items = list(range(1000))
target = 999
print(target in items)
```

## 易错点

- 频繁 `in list` 应改 set。
- dict 按键 O(1) 平均。
