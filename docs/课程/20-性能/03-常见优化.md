# 20.3 常见优化

> 前置：20.1 timeit · 约 25 分钟 · 官方对应：[性能提示](https://docs.python.org/zh-cn/3/faq/programming.html#what-is-the-most-efficient-way-to-concatenate-many-strings-in-python)

## 目标

- 用 join 代替循环 += 拼字符串
- 用局部变量减少属性查找

## 核心概念

```python run
parts = ["a", "b", "c"]
print("".join(parts))
```

## 易错点

- 过早优化浪费。
- 算法级优化优先于微优化。

## 读代码

大量 JSON 拼接用 join 或 io.StringIO；读 hot path。

## 练习

```python exercise id=s20-l03-opt
# --- starter ---
s = ''
for p in ['a','b']:
    s = s + p
s = s + 'extra'
# --- solution ---
s = ''.join(['a','b'])
# --- check ---
assert s == 'ab'
```

## 小结

- join 拼字符串
- 先 profile
