## 卡死根因（D8）

- **现象**：`npm run verify` 中 `verify-pyodide.mjs` 在主线程同步调用 Pyodide `course_run`；遇到阶段 18 等含 `threading` / 进程池的 `python run` 块时可能长时间阻塞，整次验证无法在合理时间内结束（v2.1 仅分段跑 verify）。
- **修复**：`site/scripts/verify-pyodide-worker.mjs` + 单块默认 **20s** 超时；`python local` / `python local exercise` 跳过 Pyodide；违规 API 从 `python run`/`exercise` 迁到 `python local`（`check_course.py` 仍本地真实执行）。
