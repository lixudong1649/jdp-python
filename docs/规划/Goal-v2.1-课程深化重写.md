## 内容质量底线（每课都必须满足，逐课对照）
1. **手写正文，禁止用生成脚本或模板批量填充**。删除 `scripts/bootstrap_v2_courses.py`、`scripts/bootstrap_v2_courses_data.py`。
2. 篇幅：每课正文 ≥ 150 行（不含 frontmatter），与 v1 同量级。
3. 核心概念：分 2–4 个 `###` 小节，由浅入深，每节先讲为什么、再讲怎么用；**≥ 3 个可运行示例**（`python run`），示例要有真实输出、带行内注释，不允许 `print(hasattr(...))` 这类空示例。
4. 易错点：≥ 3 条，至少 1 条配 `python run raises=…` 或对比示例。
5. 对照：与 JS / Java 的真实差异表，≥ 3 行，**禁止出现“见官方文档”“—”占位**。
6. 读代码：引用仓库内真实代码（v1 的 `minimal_agent.py` 或本阶段项目）逐行讲解 ≥ 10 行。
7. 练习：**≥ 2 道判题练习**，至少 1 道需要写 5 行以上逻辑（函数/类/循环），starter 必须让 check 失败；禁止“把名字赋值给某个库函数”式练习。
8. 小结 3–5 条；延伸阅读只用官方链接。
9. 版本表述：核对日期 2026-10-18；最新稳定 3.15（2026-10-09），3.10 已 EOL，free-threaded 3.14 起官方支持非默认；项目固定 3.12，新特性标“3.x 起”。
10. L5（21–23）依赖第三方库的示例用静态 `python` 块，并在 `examples/项目/` 放可运行、带测试的完整版本；课文里给出运行命令和期望输出。
